# DeliverEats – UAT Test Cases (v1.1)

> Simulated Business Analyst portfolio project (DeliverEats v1.1, MVP scope). Not a real production system.

**Status: all scenarios are Planned (not executed).** No working application exists, so no UAT has been run. Record outcomes in `UAT_Test_Cases_and_Results.xlsx` once testing is performed.
